# ربط نموذج اللاعب ثلاثي الأبعاد

ضع ملف النموذج هنا بالاسم `player.glb` ليتم تحميله تلقائياً لكل لاعب وحارس: `res://assets/player.glb`.

## مواصفات النموذج
- نموذج بشري ثلاثي الأبعاد منخفض/متوسط التفاصيل ومناسب للأجهزة الضعيفة والمتوسطة.
- يفضّل أن يكون اتجاه الوجه نحو محور `-Z`، والارتفاع قريباً من 2 متر، ومقياس النموذج مناسباً لوحدات Godot (متر تقريباً).
- أرفق هيكلاً عظمياً (Skeleton3D) ومتحكم `AnimationPlayer` داخل النموذج أو أحد أبنائه.
- أسماء الحركات التي يتعرف عليها النظام (الأسماء غير حساسة لحالة الأحرف):
  - الوقوف: `idle` أو `standing` أو `stand`
  - الجري: `run` أو `running` أو `jog`
  - العدو السريع: `sprint` أو `run_fast` أو `running_fast`
  - التسديد: `shoot` أو `kick` أو `shot`
  - التمرير: `pass` أو `passing`
  - تصدي الحارس: `save` أو `dive` أو `goalkeeper_save`

إذا غاب الملف أو لم يمكن تحميله، يعود المشروع تلقائياً إلى اللاعب الإجرائي الحالي.

ملاحظة: لم يتم تضمين نموذج GLB تجريبي؛ يلزم توفير ملف مرخّص للاستخدام وإضافته إلى هذا المجلد لاختبار الربط الفعلي.
